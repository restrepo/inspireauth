Counting rules

Taken from the notebooks in INSPIREHEP_new_nbs/ that produced the paper's figures.

  • A country's papers are the papers of its author records whose affiliation is one of the country's institutions, each counted once (by INSPIRE record id).
  • Authors are the distinct INSPIRE BAIs among the country's records; an author is active with a paper from 2017 or later.
  • Citations are summed over the country's papers; the h-index is computed on them.
  • Table 6 counts distinct declared positions; Table 7 counts distinct paper, author and position combinations.
  • Per million inhabitants uses the UN populations of Table 1.
  • Collaboration: share of the row country's papers that also belong to the column country.
  • Ranks and mobility: as in students.ipynb, authors with a declared rank in a country and the distinct institution, rank and period of the ranked papers they published.
  • Gender: inferred offline from the first given name and the country of the author's first record, with the genderize-offline 0.1.0 package (PyPI), built on the World Gender Name Dictionary 2.0 (WGND, CC0), in place of genderize.io; known at probability 0.9 or more. Where both give a gender they agree for 99.6% of authors.

Run it yourself

The scripts are in reproduce/ of the inspireauth repository. They need only the Python standard library and the genderize-offline package, and run in a few seconds.

pip install genderize-offline==0.1.0
python reproduce/reproduce.py data/inspire_LA.json results.json
python reproduce/compare.py ../jdis-version.tex results.json page_data.json
python reproduce/export_dashboard.py page_data.json dash/

Not recomputed here: the global output (Tables 3–4, INSPIRE-HEP queries) and the OpenAlex comparison (Sect. 8).
