HECAP Latin America boards

Each board recomputes the tables and figures of Statistical Analysis of Scientific Metrics in High Energy, Cosmology, and Astroparticle Physics in Latin America (Morales-Alvarado, Quevedo, Ramos-Hamud, Restrepo) from one version of the INSPIRE-HEP dataset of restrepo/inspireauth and compares them with the printed values. The paper's board uses the paper's data (up to 2022); the others, built when a new release of the repository is published, use a new download from INSPIRE-HEP. Every board is a self-contained page that also works offline.
